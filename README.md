# Olá, eu sou o Gabriel Pedro 👋

**Desenvolvedor Android | Java**

Sou de Jundiaí – SP e trabalho como desenvolvedor Android Java. Curso Engenharia de Software na UniAnchieta e concluí, em 2025, o Técnico em Informática (Desenvolvimento de Sistemas) integrado ao Ensino Médio nas Escolas Padre Anchieta.

### 💼 O que faço hoje

Desenvolvo e mantenho aplicativos Android nativos em Java para terminais de pagamento (POS) usados em eventos. No dia a dia, trabalho com:

- arquitetura modular com módulos e product flavors do Gradle;
- integração com SDKs de pagamento e de impressão térmica;
- persistência local com SQLite e sincronização com APIs REST via Retrofit;
- consultas SQL para relatórios de vendas.

### 🚀 Projetos

- **Neo Transportes** – SaaS para controle de presença e rotas de vans escolares, com NestJS, React Native e Google Cloud. *(em desenvolvimento)*
- **Deskly** – sistema de chamados de TI em Python (Flask) e MySQL, desenvolvido em grupo na faculdade, onde atuo como líder técnico.
- **ERP para quadras esportivas** – sistema de gestão, agendamento e controle financeiro de complexos esportivos, feito em PHP e MySQL como TCC do curso técnico.
